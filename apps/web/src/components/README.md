# Shared components

Các thành phần giao diện dùng chung như nút, form field, modal, bảng và trạng thái tải.

- `AppShell`: thanh trên cùng gồm logo, menu lọc theo quyền (`lib/navigation.ts`), tên người dùng, nút đăng xuất.
- `PagePlaceholder`: khung tạm cho trang đã có route và phân quyền nhưng chưa làm nội dung.

Class CSS dùng chung trong `app/globals.css`: `button`, `button-ghost`, `field`, `form-error`, `table`, `state`, `placeholder`, `page-section`, `page-title`.
